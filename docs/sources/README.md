# Mirrored sources

Full-text copies of open-licence sources cited by the signal inventory.
Each file carries a provenance header: source URL, DOI, retrieval date, licence, and the sha256
of the retrieved bytes. Served at `/sources/<file>` and linked from every signal drawer in the
Blanket Builder.

**Mirroring rule** (see `docs/EVIDENCE-AND-LANGUAGE-CONTRACT.md`):
- Open licence (CC-BY, CC0, public domain, PMC open subset) -> full text mirrored here.
- All rights reserved / paywalled -> NOT mirrored. The signal carries metadata, the short quotes
  relied upon, and the link to the original, and is marked `localCopy: null` with the reason.

We never present a mirrored copy as our own work, and we never pretend to hold what we do not hold.
